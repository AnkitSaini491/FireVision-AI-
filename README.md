# 🔥 FireVision AI

FireVision AI is a computer vision-based fire detection and alert system built using Python and OpenCV.

## 🚨 Features

- 🔥 Fire region detection
- 🔴 Red bounding boxes for detected fire
- 🚨 FIRE ALERT status
- 🟢 System NORMAL status
- 📊 Real-time monitoring HUD
- 🎥 Video analysis
- 📹 Camera/monitor status
- 🖥️ OpenCV-based GUI

## 🛠️ Technologies

- Python
- OpenCV
- NumPy
- Computer Vision
